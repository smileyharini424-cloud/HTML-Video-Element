# HTML Video Element

## Explanation

This project demonstrates how to add a video to a webpage using the HTML5 `<video>` element.

## Problem Statement

Create an HTML webpage that displays a video with controls such as play, pause, volume, and fullscreen.

## Features

* Video playback
* Play and pause controls
* Volume control
* Fullscreen support
* HTML5 video element

## How It Works

The `<video>` element is used to embed video content in an HTML webpage.

The `controls` attribute displays the browser's built-in video controls.

The `<source>` element specifies the video file and its format.

The `width` attribute controls the displayed width of the video.

## Technologies Used

* HTML5

## Program Flow

1. Open the webpage.
2. The video player is displayed.
3. Click the Play button.
4. Watch the video.
5. Use the controls to pause, adjust volume, or enter fullscreen mode.

## Sample Input

Video file: `sample.mp4`

## Sample Output

A video player is displayed on the webpage with playback controls.

* `<source>` element
* `controls` attribute
* `width` attribute
* Embedding multimedia in HTML
